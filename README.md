# SW SeriesBuilder

剧集（番剧）文件夹生成器

> ## ⚠️ 开发中（Work In Progress）
>
> **本项目仍在开发中**，尚未发布任何正式版本。
>
> - 界面布局、输入字段、文件夹命名规则、配置格式**都可能随时改动**，不保证向后兼容；
> - 部分功能是**占位**（点得到但没实现），详见下面的「当前状态」；
> - 代码结构也还在动，暂时不承诺 API / 模块划分的稳定性。
>
> 欢迎试用和提意见，但**先别把它当成日用工具**。

给番剧收藏做「建文件夹脚手架」的小工具：选一个根目录，填好年份、名称和每一季的季编号/年份/名称/集数，它就把整棵目录树连同空模板、占位文件一次建好；也可以直接粘一个 TMDB 链接，让它把节目与季的信息自动填进来。

技术栈：**C# / WPF / .NET 10**，**零第三方依赖**（不用任何 NuGet 包，JSON、HTTP 全用 BCL）。

## 主要功能

### 1. 新建番剧文件夹（核心）

填好之后点「开始新建」，它按这个规则建：

| 对象 | 命名规则 | 例子 |
|---|---|---|
| 根文件夹 | `{年份}《{名称}》[tmdb={编号}]` | `2024《葬送的芙莉莲》[tmdb=12345]` |
| 每季目录 | `{年份}《{名称}》{季编号}` | `2024《葬送的芙莉莲》S01` |
| 占位文件 | `《{名称}》{季编号}E{集号}.disc`（0 字节） | `《葬送的芙莉莲》S01E01.disc` |

- **TMDB 编号为空时**，根文件夹名里的 `[tmdb=...]` 整段省略；
- **季编号**：界面预填 `S00`~`S11`（`S00` 是特别篇，`S01` 是必填行，`S02`~`S11` 是名称后接数字），清空会被拦下；
- **集数**决定生成几个占位文件（`E01` ~ `E{集数}`）；
- 「新建占位文件」勾选框在「从TMDB获取」卡片右侧，勾上才生成；
- 复制模板时**先复制目录与文件、再落占位文件**，顺序不能反。

### 2. 从 TMDB 获取

在「从TMDB获取」卡片里粘链接（或直接填编号）→ 点「获取信息」：

1. 先解析出 TMDB 编号并**立刻填进「TMDB编号」**；
2. 再取剧集信息，取到了才**覆盖**节目（年份 / 名称）与每一季（季编号 / 年份 / 名称 / 集数）。

支持的输入写法：

```
https://www.themoviedb.org/tv/56351-the-world-god-only-knows
https://www.themoviedb.org/tv/56351
https://www.themoviedb.org/tv/56351/season/3     ← 带季的链接也认，取剧集编号
https://api.themoviedb.org/3/tv/1396?language=zh-CN
1396                                             ← 直接填数字
```

走的接口是 `GET https://api.themoviedb.org/3/tv/{series_id}?language=zh-CN`，用**你自己**的 TMDB **API Read Access Token** 鉴权（放在请求头里，v4 方式）。

### 3. 模板

程序目录下 `template\new folder\` 里的**每个子文件夹**都会成为下拉里的一个模板，例如自带的：

```
template\new folder\模板1\
├─ 1.1.名称\       1.日文名：.txt  2.罗马音：.txt  3.英文名：.txt  4.中文名：.txt  发行：.txt
├─ 1.2.链接\
├─ 2.1.封面+标题\   分集标题.txt
└─ 2.2.剧照\
```

新建时把选中的模板整份复制到每一季的目录里；模板读不到时会**跳过复制、其余步骤照常**（状态行会说明）。

## 快速开始

### 环境要求

- **Windows 10 / 11**（WPF 应用，不支持其它平台）
- 编译：**.NET 10 SDK**（Windows 上自带 WPF 支持）
- 只运行编译产物：**.NET 10 Desktop Runtime**

### 编译运行

```powershell
git clone <仓库地址>
cd "SW SeriesBuilder"

# 编译
dotnet build "SW SeriesBuilder.csproj" -c Release

# 运行
dotnet run --project "SW SeriesBuilder.csproj"
```

或者用 Visual Studio 2022 打开 `SW SeriesBuilder.csproj` 直接 F5。

### 配置 TMDB 令牌（只在使用「从TMDB获取」时才需要）

令牌**不进源码、不进仓库**，放在程序目录下：

```
<程序目录>\cfg\tmdb-key.txt        ← 文件内容就是一行令牌，可带 # 注释行
```

- 程序目录指 **exe 所在的目录**：VS 里调试时是 `bin\Debug\net10.0-windows\`，自己发布后就是发布目录；
- 令牌从 TMDB 网站取：登录 → 头像 → Settings → API → 复制 **API Read Access Token**（`eyJ` 开头那一长串）；
- 文件不存在或为空时，点「获取信息」会提示**完整路径**，照着放就行。

> 🔐 **不要把 `cfg\tmdb-key.txt` 提交到仓库。** 建议加进 `.gitignore`。

## 数据与配置文件

| 路径 | 用途 | 要提交吗 |
|---|---|---|
| `template\new folder\<模板名>\` | 内置模板，随程序走 | 要 |
| `图标\程序内使用图标\*.svg` | 界面图标的 SVG 源文件 | 要 |
| `图标\程序图标\icon.ico` | 程序图标（同时驱动 exe 图标与标题栏） | 要 |
| `cfg\设置.json` | 记住上次的根目录与模板（程序自己写） | **不要** |
| `cfg\tmdb-key.txt` | TMDB 令牌 | **绝对不要** |
| `bin\` `obj\` | 编译产物 | **不要** |

## 项目结构

```
SW SeriesBuilder\
├─ 窗口_主界面.xaml(.cs)     界面：三张「孤岛卡片」+ 三个模式面板
├─ 样式\
│  ├─ 配色.xaml              全部颜色（改配色只动这个文件）
│  └─ 控件样式.xaml           控件样式 + 界面图标（SVG 转成的 WPF 几何）
├─ 模块\
│  ├─ 新建番剧文件夹.cs        建目录的全部规则（校验 / 命名 / 落盘）
│  ├─ TMDB获取.cs             TMDB：链接解析 / 令牌读取 / 响应解析 / 填表
│  ├─ 界面状态.cs             数据模型（节目三项 + 12 行季 + 模板列表）
│  ├─ 配置.cs                 cfg\设置.json 的读写
│  ├─ 模板查找.cs             扫描 template\new folder\
│  ├─ 无边框标题栏.cs          自绘标题条 + 系统非客户区处理
│  └─ …（弹出动画 / 程序图标 / 标题栏深色 / 界面状态）
├─ 子窗口\                    深色提示窗、关于窗
└─ template\new folder\       内置模板
```

**两条硬口径**：

1. **逻辑与界面分离** —— `模块\新建番剧文件夹.cs`、`界面状态.cs`、`TMDB获取.cs` **不引用 WPF**，所以能在控制台里真跑（下面那套用例就靠这个）；
2. **零 NuGet** —— 只用 BCL（`System.Text.Json`、`HttpClient` 等），配色与样式全部写死成 `StaticResource`。

## 已知限制

- 一次最多 **12 季**（界面行数固定，对应季号 `S00`~`S11`）；TMDB 返回更多季时会跳过并说明是哪几季；
- 「重命名文件」「图片替换」两个模式还是空壳；
- 只做了中文界面；
- 没有安装包，也没有单文件发布说明；
- TMDB 功能需要你自己准备令牌，否则只有手填这一条路。
